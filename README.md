# Secure Small Office Network Design

## Overview

Designed and implemented a secure small office network using Cisco Packet Tracer.

The project includes router and switch configuration, VLAN segmentation, DHCP services, trunk links, port security, SSH remote management, and connectivity testing.

## Features

- Router Configuration
- Switch Configuration
- VLAN Segmentation
- DHCP Services
- Trunk Links
- Port Security
- SSH Remote Management
- End-to-End Connectivity Testing
